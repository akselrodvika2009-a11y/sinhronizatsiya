# Синхронизация

Концерт, где ты гарантировано встретишь свою любовь.

## Структура

```
├── assets/          # картинки (планета-сердце, одежда, иконки)
├── fonts/           # локальные шрифты (если понадобятся)
├── styles/
│   ├── reset.css
│   ├── fonts.css
│   ├── layout.css
│   └── style.css
└── index.html
```

Шрифт: **Montserrat** (подключён через Google Fonts).

Пока это начальный каркас под макет из Figma. Картинки и точные стили добавим позже.
